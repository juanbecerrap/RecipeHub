# RecipeHub: frontend

Aplicación web de RecipeHub, construida con Angular.

La documentación completa del proyecto (descripción, instalación, configuración de la base de datos y de la API) está en el [README principal](../README.md).

## Comandos

Ejecútalos desde esta carpeta (`frontend`):

- `npm start`: servidor de desarrollo en <http://localhost:4200>. Necesita la API en marcha.
- `npm run build`: compilación de producción en la carpeta `dist/`.
- `npm test -- --no-watch`: pruebas unitarias.
