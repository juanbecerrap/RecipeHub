# RecipeHub

Descubre, organiza y prepara tus recetas favoritas.

RecipeHub es una aplicación web para explorar y gestionar recetas de cocina: catálogo con búsqueda y filtros, detalle de cada receta y administración completa de las recetas.

> Proyecto en construcción. Este documento se ampliará al terminar el desarrollo, con la guía de instalación, la descripción técnica y las capturas de pantalla.

## Estructura del repositorio

- `frontend/`: aplicación web.
- `backend/`: API REST.
- `database/`: scripts SQL de creación y datos iniciales.
